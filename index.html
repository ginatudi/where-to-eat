How to use
  1. Tap the + button to add a place.
  2. Tap the circle when you have been.
  3. Give stars and say if you would go back.
  4. Use Spin to let the wheel decide.
More details

Both of you see the same list and changes show up live. The Spin tab uses whatever filters are set, so leave it on "Not been" to pick somewhere new.

The map pins come from the address you type. Purple pins are places you have not been, blue pins are places you have. If a pin is missing, edit the place and make the address more complete.

On iPhone, open the site in Safari, tap Share, then "Add to Home Screen".
